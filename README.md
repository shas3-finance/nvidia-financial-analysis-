# NVIDIA Financial Analysis

## Overview

This project develops a Python-based financial model to forecast NVIDIA's revenue, estimate its weighted average cost of capital (WACC), calculate discounted cash flow (DCF) valuation, and analyse valuation sensitivity to changes in WACC and terminal growth.

The project is designed to demonstrate practical financial modelling, valuation and Python skills relevant to investment banking, asset management, equity research and private credit.
